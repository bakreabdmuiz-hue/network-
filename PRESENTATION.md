# Network Intrusion Detection with Unsupervised Learning and Statistical Methods

Network defenses can miss attacks that do not match known signatures, so this project explores how to flag unfamiliar behavior by learning a baseline of normal network-flow summaries. It combines Isolation Forest with median/MAD statistical outlier checks over duration, bytes, packets, destination port, and protocol; when a flow differs enough from the baseline, the system raises an alert that shows its score, severity, and unusual features for analyst review. In the offline synthetic demo, the detector scored 18 flows and raised 4 alerts: three deliberately injected outliers and one likely false positive, illustrating both the potential to surface unknown behavior and the need for human review. This is a prototype, not a guarantee of zero-day detection; next steps are to evaluate it on a separate labeled dataset, measure precision, recall, false-positive rate, and detection delay, and tune thresholds while monitoring traffic drift. The demo uses synthetic flow summaries only and does not capture live traffic.
